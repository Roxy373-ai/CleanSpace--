# CleanSpace

CleanSpace 是完全本地运行的 Windows 磁盘分析与安全清理工具。文件名、照片、视频和扫描结果不会上传。

CleanSpace는 파일 이름, 사진, 동영상, 검사 결과를 업로드하지 않는 Windows용 로컬 디스크 분석 및 안전 정리 도구입니다.

## 功能 / 기능

- 自动识别系统盘、固定盘和可移动盘，可选择仅扫描系统盘或扫描所有本地磁盘。 / 시스템 드라이브, 고정 드라이브, 이동식 드라이브를 자동으로 찾고 시스템 드라이브만 또는 모든 로컬 드라이브를 검사합니다.
- 按安全、需确认和禁止直接处理三类显示临时文件、应用与浏览器缓存、缩略图缓存、崩溃转储、更新下载残留和旧下载文件。 / 임시 파일, 앱 및 브라우저 캐시, 미리 보기 캐시, 오류 덤프, 업데이트 다운로드 파일, 오래된 다운로드 파일을 위험도에 따라 구분합니다.
- 分析大文件、精确重复文件、相似照片候选和损坏媒体。 / 대용량 파일, 정확한 중복 파일, 비슷한 사진 후보, 손상 의심 미디어를 확인합니다.
- 已安装软件显示图标；官方卸载后只检查明确关联的残留项目。 / 설치된 프로그램의 아이콘을 표시하고 공식 제거 뒤에는 분명히 연결된 잔여 항목만 확인합니다.
- 简体中文与韩文即时切换。 / 중국어 간체와 한국어를 바로 전환할 수 있습니다.

## 安全边界 / 안전 경계

默认清理会移入 Windows 回收站。使用“不移入回收站”前需要再次确认。系统目录、程序核心文件和扫描后发生变化的文件不会直接处理。相似照片、疑似损坏媒体和注册表残留都需要用户自己确认；注册表项不会自动删除。

기본 정리는 Windows 휴지통으로 이동합니다. 휴지통을 거치지 않는 작업은 다시 확인해야 합니다. 시스템 경로, 프로그램 핵심 파일, 검사 뒤 바뀐 파일은 직접 처리하지 않습니다. 비슷한 사진, 손상 의심 미디어, 레지스트리 잔여 항목은 사용자가 직접 확인해야 하며 레지스트리 항목은 자동으로 삭제하지 않습니다.

## 源码位置 / 소스 위치

源码仅保留在发布者本机，不上传到这个公开仓库。普通用户请下载 Release 中的 v1.2.1 Windows x64 发布包。

소스 코드는 게시자의 로컬 컴퓨터에만 보관하며 이 공개 저장소에는 올리지 않습니다. 일반 사용자는 Release의 v1.2.1 Windows x64 배포 파일을 받으면 됩니다.

## 发布包 / 배포 파일

v1.2.1 Windows x64 发布包解压后双击 CleanSpace.exe 即可运行，无需安装 Python、.NET 或 VS Code。

v1.2.1 Windows x64 배포 파일은 압축을 푼 뒤 CleanSpace.exe를 두 번 클릭하면 실행됩니다. Python, .NET, VS Code를 따로 설치할 필요가 없습니다.
