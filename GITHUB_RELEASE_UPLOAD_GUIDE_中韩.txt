CleanSpace v1.2.1 GitHub 发布说明 / GitHub 배포 안내
=======================================================

中文
----
GitHub 仓库应包含源码和必要的构建配置，不应包含 .tools、bin、obj、dist-dotnet、扫描结果、缓存或个人文件。

建议的 Release 设置：
- Tag：v1.2.1
- 标题：CleanSpace v1.2.1 Windows x64
- 附件：CleanSpace_허준영_v1.2.1_win-x64.zip
- 说明：粘贴 RELEASE_NOTES_v1.2.1_中韩.txt 的内容

下载者解压 ZIP 后双击 CleanSpace.exe 即可运行，不需要 Python、.NET 或 VS Code。发布 ZIP 前请保留同目录的 SHA256 校验文件。

한국어
------
GitHub 저장소에는 소스 코드와 필요한 빌드 설정만 올립니다. .tools, bin, obj, dist-dotnet, 검사 결과, 캐시, 개인 파일은 올리지 마세요.

권장 Release 설정:
- Tag: v1.2.1
- 제목: CleanSpace v1.2.1 Windows x64
- 첨부 파일: CleanSpace_허준영_v1.2.1_win-x64.zip
- 설명: RELEASE_NOTES_v1.2.1_中韩.txt 내용을 붙여 넣습니다.

사용자는 ZIP을 푼 뒤 CleanSpace.exe를 두 번 클릭하면 됩니다. Python, .NET, VS Code가 필요하지 않습니다. ZIP을 게시하기 전에 같은 폴더의 SHA256 확인 파일을 함께 보관하세요.
