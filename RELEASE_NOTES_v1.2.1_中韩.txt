CleanSpace v1.2.1 Windows x64
作者 / 제작자: 허준영

中文
----
本版本改进了 Windows 磁盘分析与安全清理流程：

- 自动识别当前系统盘、固定磁盘和可移动磁盘，可选择仅扫描系统盘或扫描所有本地磁盘。
- 增加临时文件、应用与浏览器缓存、缩略图、崩溃转储、更新下载残留、久未使用下载文件等安全分级候选项。
- 重复文件支持批量加入和移出清理清单；双击文件会正常打开，不再逐项弹出确认窗口。
- 增加相似照片候选检查和损坏媒体检查。相似或疑似损坏的媒体不会自动选中。
- 软件管理显示应用图标；官方卸载完成后可只检查与该软件明确关联的文件夹和注册表项。
- 普通模式即可使用大部分功能；需要更高权限时会说明原因，并提供管理员模式入口。

安全说明：默认清理会移入 Windows 回收站。单独的“不移入回收站”操作需要再次确认。系统、程序核心目录和扫描后已变化的文件不会直接处理。注册表残留只展示来源和路径，不会自动删除。

한국어
------
이번 버전에서는 Windows 디스크 분석과 안전 정리 흐름을 다듬었습니다.

- 현재 시스템 드라이브, 고정 드라이브, 이동식 드라이브를 자동으로 찾습니다. 시스템 드라이브만 검사하거나 모든 로컬 드라이브를 검사할 수 있습니다.
- 임시 파일, 앱과 브라우저 캐시, 미리 보기 캐시, 오류 덤프, Windows 업데이트 다운로드 파일, 오래된 다운로드 파일을 위험도에 따라 구분합니다.
- 중복 파일은 한 번에 정리 목록에 넣거나 뺄 수 있습니다. 파일을 두 번 클릭하면 열리며, 항목마다 확인 창이 뜨지 않습니다.
- 비슷한 사진 후보와 손상 의심 미디어를 확인할 수 있습니다. 비슷하거나 손상 의심인 미디어는 자동으로 선택하지 않습니다.
- 프로그램 관리 화면에 앱 아이콘을 표시합니다. 공식 제거가 끝난 뒤에는 해당 프로그램과 분명히 연결된 폴더와 레지스트리 항목만 확인합니다.
- 대부분의 기능은 일반 권한으로 사용할 수 있습니다. 추가 권한이 필요하면 이유를 안내하고 관리자 모드로 다시 시작할 수 있습니다.

안내: 기본 정리는 Windows 휴지통으로 이동합니다. 휴지통을 거치지 않는 작업은 다시 확인해야 합니다. 시스템과 프로그램 핵심 경로, 검사 뒤 바뀐 파일은 직접 처리하지 않습니다. 레지스트리 잔여 항목은 출처와 경로만 보여 주며 자동으로 삭제하지 않습니다.
